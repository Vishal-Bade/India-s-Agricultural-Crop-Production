# India's Agricultural Crop Production Analysis

## Project Overview

This project analyzes India's agricultural cultivation and crop production trends from 1997 to 2021. Using Tableau and Flask, it offers an interactive platform for exploring regional distribution, seasonal variations, and crop yields.

## Key Features

- **Interactive Tableau Dashboard**: Visualizes crop production, regional distribution, and seasonal variations.
- **Tableau Story**: Guide stakeholders through long-term trends and key agricultural insights.
- **Scenario-Based Insights**:
  - **Small-Scale Farmer**: Assist in making crop selection decisions based on historical patterns.
  - **Government Policy Analyst**: Identify regions with low crop yields to assist with resource allocation and policymaking.
  - **Agribusiness Investor**: Help identify high-growth agricultural sectors and profitable crops.

## Tech Stack

- **Frontend**: HTML5, CSS3, Bootstrap 5
- **Backend**: Python, Flask
- **Data Visualization**: Tableau Public
- **Environment**: Python Virtual Environment (`.venv`)

## Running the Project

1. Activate the virtual environment:
   ```powershell
   .venv\Scripts\activate
   ```
2. Start the Flask application:
   ```powershell
   python app.py
   ```
3. Open your browser and navigate to `http://127.0.0.1:5000`.
